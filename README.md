# 고슐랭

고민수가 직접 먹어보고 고른 맛집 목록.

- 기준서: `criteria.md`
- Claude Code 작업 지침: `CLAUDE.md` (Claude Code가 자동으로 읽음)
- 식당 데이터: `data/{시도}/{상호}.md` — 식당 1곳 = 파일 1개
- 새 식당 양식: `template.md`
- 목록 페이지: `index.html` (`python3 build.py`로 생성)

## Claude Code에 이렇게 지시하면 됩니다

- "서울 사당 근처 후보 5곳 찾아줘"
- "안양 노포 후보 찾아줘"
- "선정된 곳 중 주소가 비어 있는 곳 채워줘"
- "최종확인일이 6개월 지난 곳 폐업 여부 확인해줘"

Claude Code는 새 브랜치에서 작업하고 Pull Request로 올립니다. 내용을 확인한 뒤 반영(Merge)하면 됩니다.

## 내가 직접 고치는 칸

`상태`(답사 예정·선정·보류·탈락), `등급`(1·2·3), `태그`, `분위기유형`, `가점`, `감점`, `## 고민수 한줄평`
— Claude Code는 이 칸을 건드리지 않습니다.
